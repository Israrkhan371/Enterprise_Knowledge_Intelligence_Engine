Admin session

Admin endpoints require a real admin user's UUID via the X-User-Id header. Set it once here — it's stored in your browser only.

Don't have one? Create it once from the host machine:

docker exec -it ekie-postgres psql -U ekie -d ekie -c "INSERT INTO users (id, email, name, role) VALUES (gen_random_uuid(), 'admin@ezitech.test', 'Admin', 'admin') RETURNING id;"

Leave as /api/v1 when this page is served by the API itself (the default). Only change this if you're hosting the frontend separately from the backend.
