# Ezitech Engineering Framework Overview

**Document type:** Program overview
**Owner:** Ezitech Engineering Enablement

## What the EEF is

The Ezitech Engineering Framework (EEF) is the structure behind every
industry AI case study interns work through — a consistent format for
scoping, running, and evaluating multi-week project-based case studies
(e.g. AI-007, the Enterprise Knowledge Intelligence Engine).

## Standard case-study deliverables

Every EEF case study, regardless of topic, requires the same deliverable
set so mentors can evaluate consistently across tracks:

- Complete source code
- Architecture diagram
- Database schema (and, where applicable, knowledge graph design)
- API documentation
- Evaluation report
- Deployment guide
- README
- Technical presentation
- Live demonstration

## Standard evaluation dimensions

Case studies are scored across the same dimensions (weights vary by
case study — see the specific case study document for exact weighting):
architecture quality, functional accuracy, scalability, business value,
documentation quality, innovation, and presentation.

## Team structure

Most EEF case studies run with a small team (2 engineers is typical),
over a fixed multi-week duration, with a weekly tracker used to log task
status, ownership, and completion evidence.
