# Intern Onboarding Checklist

**Document type:** Onboarding checklist
**Owner:** Ezitech Engineering Enablement
**Applies to:** New interns joining any EEF case study track.

## Before day 1

- [ ] Signed intern agreement on file with HR.
- [ ] Ezitech email account created.
- [ ] Assigned to a mentor and a case-study track.

## Week 1

- [ ] Complete IT access request for GitHub, Slack, and the LMS
      (see SOP - Access Request Process).
- [ ] Read the case study packet for your assigned track in full.
- [ ] Read Ezitech Python Coding Standards and SOP - Code Review Process.
- [ ] Attend the mentor kickoff check-in.
- [ ] Set up local dev environment and confirm the starter repo runs.
- [ ] Join the case-study team's working channel.

## Ongoing

- [ ] Attend weekly check-ins with your mentor.
- [ ] Keep the weekly tracker updated with task status and evidence
      (what was verified, how, and any bugs found/fixed).
- [ ] Escalate blockers per SOP - Escalation Procedures rather than
      letting them sit past a check-in cycle.

## Before the final week

- [ ] Confirm all deliverables from the case study document are either
      complete or explicitly scoped out with a documented reason.
- [ ] Schedule the live demonstration slot with your mentor.
